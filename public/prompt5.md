Jadikan ini salah satu slide PALING VISUAL dan IMPRESSIVE.

WAJIB melakukan research mengenai:

- enterprise account prioritization
- cybersecurity sales pipeline
- B2B SaaS sales pipeline
- account-based selling
- enterprise opportunity management

==================================================
PRIMARY CONCEPT
==================================================

Buat:

INTERACTIVE SALES PIPELINE COMMAND CENTER

==================================================
ACCOUNT MAP
==================================================

Gabungkan:

INDONESIA MAP
+
TARGET ACCOUNT
+
PIPELINE

Setiap account menjadi node.

Ketika account dipindahkan ke stage pipeline:

Prospect
→
Qualified
→
Discovery
→
Demo
→
PoC
→
Proposal
→
Negotiation
→
Won

node berubah posisi / status secara animated.

==================================================
DRAG INTERACTION
==================================================

Jika memungkinkan, buat account dapat:

DRAG & DROP

antar pipeline stage.

Contoh:

Company A

dari:

Qualified

dipindahkan ke:

Demo

Maka:

pipeline count
pipeline value
stage distribution

otomatis berubah.

==================================================
PIPELINE VALUE
==================================================

Gunakan angka besar:

TOTAL PIPELINE
QUALIFIED PIPELINE
ACTIVE OPPORTUNITIES
WIN RATE
PIPELINE COVERAGE

Jika menggunakan angka ilustratif:

jelaskan:

ILLUSTRATIVE 90-DAY MODEL

Jangan membuat angka tersebut terlihat seperti data aktual.

==================================================
CHARTS
==================================================

Gunakan kombinasi:

Funnel Chart
Bar Chart
Line Chart
Donut Chart
Pipeline Distribution
Conversion Chart

Jangan semuanya sekaligus jika membuat visual terlalu penuh.

==================================================
ACCOUNT SCORING
==================================================

Gunakan:

Potential
Fit
Urgency
Access
Probability

Buat composite score.

Tampilkan sebagai:

bubble size
circle
position
heatmap

bukan badge.

==================================================
MAP + PIPELINE
==================================================

Contoh:

Jakarta
● Account A
● Account B
● Account C

Bandung
● Account D

Surabaya
● Account E

Ketika account dipilih:

map focus
+
account profile
+
pipeline stage
+
next action

==================================================

Next Action
